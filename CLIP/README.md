# CLIP 图像-文本匹配项目

基于 OpenAI CLIP（Contrastive Language-Image Pre-training）模型的图像和文本相似度匹配项目。本项目实现了CLIP和BLIP模型的核心模块，可用于图像-文本检索、零样本分类等任务。

## 📋 项目信息

- **项目名称**：CLIP_Project
- **项目类型**：深度学习/多模态
- **Python版本**：3.13
- **作者**：[王子琛]
- **创建时间**：2026年3月
